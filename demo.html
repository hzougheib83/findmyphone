Test context

This is a recording of the actual app running on an Android emulator. Incoming trusted calls are simulated through Android Emulator telephony. All profile details and phone numbers are fictional. This is a silent screen recording; it has no audio track.

The test verifies that the two-call trigger starts the real foreground alarm service, the alarm screen displays phone-return details, and the configured password stops the service. It is not a physical cellular-network or manufacturer-specific acceptance test.

What the recording shows

  1. The configured app reports ready to ring.
  2. The screen is turned off; two trusted incoming calls are simulated within 30 seconds.
  3. The alarm screen shows the fictional owner name and return-contact number.
  4. The configured stop password is entered and the alarm screen closes. The test confirms the foreground alarm is no longer active.

On some Android configurations, the alarm screen must be opened from the ongoing notification. Full-screen display depends on user-granted access and Android settings.
